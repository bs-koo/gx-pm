# /테스트결과서 — 테스트 결과서 생성 (IM-03, TE-02, TE-06)

> **공통 규칙**: `templates/approval-protocol.md`의 승인 루프 프로토콜을 적용한다.

## 워크플로우

### Step 0: 프로젝트 컨텍스트 로드

**load-project-profile** 스킬로 활성 프로젝트를 확인한다. 프로파일이 없으면 `/프로젝트설정`을 먼저 실행하라고 안내 후 종료.

모든 유형(A/B/C/D)에서 동일하게 동작한다. 계획서 기반 결과 기입.

### Step 1: 유형 선택 [필수 중단점]

**AskUserQuestion 도구**로 다음 내용을 질문한다:

```
어떤 결과서를 작성할까요?
  1. 단위테스트결과서 (IM-03) — 개발팀, 화면 단위
  2. 통합테스트결과서 (TE-02) — 개발팀+현업, 업무 흐름
  3. 인수테스트결과서 (TE-06) — 발주처

※ 시스템테스트결과서(ST-02, 비기능)는 /시스템테스트 커맨드를 사용하세요.
```

### Step 1-1: 기존 결과서 감지

유형 선택 후, **detect-existing-artifact** 스킬로 해당 유형의 기존 파일을 확인한다:
- 단위테스트결과서 → `{시스템코드}-단위테스트결과서.md`
- 통합테스트결과서 → `{시스템코드}-통합테스트결과서.md`
- 인수테스트결과서 → `{시스템코드}-인수테스트결과서.md`

파일이 있으면 이어쓰기/새로쓰기/열기 선택. 없으면 새로 생성.

### Step 2: 계획서 로드

이전 `/단위테스트계획서` 또는 `/통합테스트시나리오` 결과 자동 로드.

### Step 3: 결과 입력 방식 선택 [필수 중단점]

**AskUserQuestion 도구**로 다음 내용을 질문한다:

```
결과 입력 방식을 선택해주세요
  1. 전체 적합 — 모든 항목 일괄 "적합"
  2. 부적합 목록 — 부적합만 입력 (나머지 자동 적합)
  3. 항목별 입력 — 하나씩 입력
```

### Step 4: 결과 기입

선택 방식에 따라 **fill-unit-test-result** 또는 **fill-integration-test-result** 스킬 적용.

판정값은 **적합 / 부적합 / 점검제외** 3종이다.
- **부적합** → **manage-defects** 스킬을 호출하여 결함ID를 발급하고 DF-01 결함관리대장에 등록한다.
  결과서에는 부적합 내역(현상)과 결함ID만 기록하고, 원인·조치·재테스트는 대장에서 관리한다.
- **점검제외** → 사유를 필수 기재한다 (환경 미준비 / 선행 기능 결함 / 외부 환경 변화 / 과업 범위 외).

### Step 5: 결과서 검토 [필수 중단점 — 승인 루프]

산출물을 마크다운 표로 출력한 후, **AskUserQuestion 도구**로 승인을 요청한다:

```
테스트 결과서를 확인해주세요.

적합률: {N}% ({적합건}/{전체건})

승인하려면 '승인' 또는 'OK'를 입력하세요.
수정하려면 변경할 내용을 입력하세요.

수정 예시:
• "TC_EHR_01_01_020_04 결과를 부적합으로, 현상: 연동 오류"
• "B-TE-002 Step 3 수행자를 '김철수'로"
```

사용자가 승인할 때까지 수정 → 재출력 → AskUserQuestion으로 승인 요청을 반복한다.

### Step 6: 결과 저장 + xlsx 추출

**AskUserQuestion 도구**로 다음 내용을 질문한다:

```
승인된 산출물을 xlsx로 추출할까요?
  1. xlsx 추출
  2. 마크다운만 저장
```

### Step 7: 종료기준 판정

총괄 테스트계획서(TE-01) §7의 종료기준과 대조하여 다음 레벨 진입 가능 여부를 판정한다.
TE-01이 없으면 기본값(케이스 실행률 100% · Critical 0 · Major 0 · Minor 조치율 90% · 적합률 95%)을 쓰고 안내한다.

### Step 8: 다음 제안

- "/결함관리대장 으로 발급된 결함을 추적할까요?"
- "/추적매트릭스 로 시험 단계와 잔존 결함을 갱신할까요?"
- 종료기준 미충족: "다음 테스트 레벨 진입 조건을 만족하지 않습니다. 미조치 결함을 확인하세요."
- 적합률 95% 미만: "부적합 항목 조치 후 재테스트가 필요합니다."
