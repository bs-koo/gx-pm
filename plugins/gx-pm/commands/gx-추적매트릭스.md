# /gx-추적매트릭스 — AN-05 추적매트릭스 생성

> **공통 규칙**: `templates/approval-protocol.md`의 승인 루프 프로토콜을 적용한다.
> **선행조건**: `templates/prerequisites.md` 의 이 커맨드 행을 따른다.
> **파이프라인**: `/gx-spec` 또는 `/gx-testplan` 에서 호출된 경우 `templates/pipeline-protocol.md` 의 규약을 따른다.

## 워크플로우

### Step 0: 프로젝트 컨텍스트 로드

**load-project-profile** 스킬로 활성 프로젝트를 확인한다. 프로파일이 없으면 `/gx-프로젝트설정`을 먼저 실행하라고 안내 후 종료.

**detect-existing-artifact** 스킬로 기존 `{시스템코드}-추적매트릭스.md` 파일을 확인한다.
- 파일 있음 → 이어쓰기/새로쓰기/열기 선택
- 파일 없음 → 새로 생성

**선행조건 검사** — `templates/prerequisites.md` 의 이 커맨드 행을 읽고:
- **하드 선행이 없으면**: 해당 선행 커맨드를 안내하고 **종료한다**. 추정으로 채우지 않는다.
- **소프트 선행이 없으면**: AskUserQuestion 으로 "그대로 진행 / 중단하고 준비" 를 묻는다.
  그대로 진행하면 산출물 비고에 "축약 생성" 을 남긴다.

파이프라인에서 호출된 경우 이 검사는 파이프라인이 이미 수행했으므로 **건너뛴다**.

프로파일의 `type`에 따라 워크플로우가 분기된다:
- **A (신규 구축)**: 전체 생성 (기존)
- **B (추가 개발)**: 기존 매트릭스에 새 요구사항 행만 추가
- **C (산출물 정비)**: 소스코드/DB 기반으로 역추적하여 매트릭스 역생성
- **D (변경 관리)**: 변경 대상 ID 체인만 갱신

### Step 1: 추적 모드 결정

- 특정 ID 입력 → 단건 추적
- "전체" → 전체 교차 검증
- 없으면 선택 요청

### [단건] Step 2a: 단건 ID 추적

**id-trace** 스킬: ID 유형 자동 판별 후 양방향 추적 체인 출력. 누락 매핑은 ⚠ 표시.

### [전체] Step 2b: 전체 교차 검증 + AN-05 생성

**trace-requirements** 스킬로 AN-05 추적매트릭스를 생성·갱신한다:
- 가용 산출물 확인 (AN-02 필수 / DE-03·DE-05·DE-04·DE-08·DE-13·DE-14·**ST-01**·**DF-01**)
- 요구사항 **구분(기능/비기능)에 따라 매핑 경로 분기**
  - 기능 → 화면 → 프로그램 · 단위테스트 · 테스트케이스 · 통합테스트
  - 비기능 → **시스템테스트ID**
- 과업완료여부 자동 판정 (**잔존 결함이 있으면 완료로 판정하지 않음**)

**id-trace** 스킬로 전체 교차 검증을 수행한다:
- 누락 7유형 탐지 (화면 미매핑 · 프로그램 미등록 · 단위테스트 미작성 · **테스트케이스 미작성** · 통합테스트 미연결 · **비기능 검증 누락** · **결함 미종결**)
- 역방향 불일치 확인
- 커버리지 산출 (화면 매핑률 · **비기능 검증률** · 테스트케이스 커버리지 · 결함 종결률)

### Step 3: 추적 결과 검토 [필수 중단점 — 승인 루프]

산출물을 마크다운 표로 출력한 후, **AskUserQuestion 도구**로 승인을 요청한다:

```
추적매트릭스 결과를 확인해주세요.

추적 완료: {N}건 / 누락: {M}건

커버리지:
  기능 화면 매핑률   {N}%
  비기능 검증률      {N}%   ← 시스템테스트 연결
  테스트케이스 커버리지 {N}%
  결함 종결률        {N}%

주요 확인:
1. 누락이 실제 누락인지, 의도적 미매핑인지
2. 비기능 요구사항은 화면 매핑이 아니라 시스템테스트ID로 검증됩니다
3. 잔존 결함이 있는 요구사항은 과업완료로 판정하지 않았습니다

승인하려면 '승인' 또는 'OK'를 입력하세요.
수정하려면 변경할 내용을 입력하세요.

수정 예시:
• "B-RE-017은 시스템테스트 B-ST-004로 연결해줘"
• "B-RE-005에 화면 EHR_02_01_010 연결해줘"
• "B-DF-011은 Deferred 승인됨. 완료로 판정해줘"
```

사용자가 승인할 때까지 수정 → 재출력 → AskUserQuestion으로 승인 요청을 반복한다.

### Step 4: 결과 저장 + xlsx 추출

파일명: `{시스템코드}-추적매트릭스.md`

**AskUserQuestion 도구**로 다음 내용을 질문한다:

```
승인된 산출물을 xlsx로 추출할까요?
  1. xlsx 추출
  2. 마크다운만 저장
```
