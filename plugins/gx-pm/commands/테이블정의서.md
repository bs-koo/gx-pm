# /테이블정의서 — DE-08 테이블정의서 생성

> **공통 규칙**: `templates/approval-protocol.md`의 승인 루프 프로토콜을 적용한다.

## 워크플로우

### Step 1: 방향 결정

- DDL 입력 → 정방향 (DDL → 테이블정의서)
- "역방향" → 역방향 (요구사항 → DDL)
- 없으면 선택 요청: (1) DDL → 테이블정의서  (2) 요구사항 → ERD + DDL

### [정방향] Step 2a: DDL → 테이블정의서

**convert-ddl-to-tablespec** 스킬: DDL 파싱, COMMENT에서 한글명 추출, 없으면 추론.

### [역방향] Step 2b: 요구사항 → DDL

**generate-erd-guide** 스킬: 엔터티 식별, 관계 도출, DDL + 테이블정의서 초안 생성.

### Step 3: 테이블 구조 검토 [필수 중단점 — 승인 루프]

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 테이블 {N}개 정의를 확인해주세요

주요 확인:
1. 한글 컬럼명이 올바른지
2. 데이터타입과 길이가 적절한지
3. PK/FK 관계가 맞는지
4. 공통 컬럼(등록일시, 수정일시 등)이 빠지지 않았는지

✅ 승인 — "승인" 또는 "OK"
✏️ 수정 — 변경 내용 입력

  수정 예시:
  • "USER_NM 컬럼명을 '사용자명'으로"
  • "STN_ID 길이를 20으로"
  • "API_CALL_LOG에 IP_ADDR 컬럼 추가"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

사용자가 승인할 때까지 수정 → 재출력 → AskUserQuestion으로 승인 요청을 반복한다.

### Step 4: 결과 저장 + xlsx 추출

파일명: `{시스템코드}-테이블정의서.md` / (역방향 시) `{시스템코드}-DDL.sql`

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 xlsx로 추출할까요?
  1. xlsx 추출 (테이블별 시트 분리)
  2. 마크다운만 저장
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
