# /감리대응 — 감리 대응 문서 생성

> **공통 규칙**: `templates/approval-protocol.md`의 승인 루프 프로토콜을 적용한다.

## 워크플로우

### Step 0: 프로젝트 컨텍스트 로드

**load-project-profile** 스킬로 활성 프로젝트를 확인한다. 프로파일이 없으면 `/프로젝트설정`을 먼저 실행하라고 안내 후 종료.

**detect-existing-artifact** 스킬로 기존 `{시스템코드}-감리대응.md` 파일을 확인한다.
- 파일 있음 → 이어쓰기/새로쓰기/열기 선택
- 파일 없음 → 새로 생성

모든 유형(A/B/C/D)에서 동일하게 동작한다. 지적사항 분류 → 조치계획 생성.

### Step 1: 지적사항 입력

텍스트, 파일 업로드, 여러 건 한꺼번에 가능.

### Step 2: 지적사항 분류

**audit-response** 스킬: 산출물누락 / 내용미흡 / 추적성부족 / 품질미달 / 절차미준수 분류.

### Step 3: 분류 결과 검토 [필수 중단점 — 승인 루프]

산출물을 마크다운 표로 출력한 후, **AskUserQuestion 도구**로 승인을 요청한다:

```
지적사항 분류 결과를 확인해주세요.

승인하려면 '승인' 또는 'OK'를 입력하세요.
수정하려면 변경할 내용을 입력하세요.

수정 예시:
• "2번은 '산출물 누락'이 아니라 '내용 미흡'"
• "추가 지적사항: 테스트 증적 미비"
```

사용자가 승인할 때까지 수정 → 재출력 → AskUserQuestion으로 승인 요청을 반복한다.

### Step 4: 영향 범위 분석 + 조치계획

**impact-analysis** 스킬 → 조치계획 수립 (지적사항/원인/조치/담당자/완료예정일/필요증빙).

### Step 5: 조치계획 검토 [필수 중단점 — 승인 루프]

산출물을 마크다운 표로 출력한 후, **AskUserQuestion 도구**로 승인을 요청한다:

```
조치계획을 확인해주세요.
담당자와 완료예정일을 입력해주세요.

승인하려면 '승인' 또는 'OK'를 입력하세요.
수정하려면 변경할 내용을 입력하세요.

수정 예시:
• "1번 담당자: 홍길동, 완료일: 2026-04-05"
• "2번에 '추적매트릭스 갱신' 추가"
```

사용자가 승인할 때까지 수정 → 재출력 → AskUserQuestion으로 승인 요청을 반복한다.

### Step 6: 결과 저장 + xlsx 추출

파일명: `{시스템코드}-감리대응.md`

**AskUserQuestion 도구**로 다음 내용을 질문한다:

```
승인된 산출물을 xlsx로 추출할까요?
  1. xlsx 추출 (조치계획 + 증빙 체크리스트)
  2. 마크다운만 저장
```

### Step 7: 후속 조치 제안

지적 유형에 따라 관련 커맨드 제안 (산출물 누락 → 해당 산출물 커맨드, 추적성 부족 → /추적매트릭스).
