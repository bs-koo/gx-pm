# gx-pm — 공공/SI PM 플러그인

## 이 플러그인은

공공/SI 프로젝트의 PM(프로젝트 매니저)을 위한 Claude Cowork 플러그인입니다.
실제 공공 프로젝트 산출물 양식(요구사항정의서, 화면목록표, 테이블정의서, 테스트계획서 등)에 맞는 데이터를 자동 생성하고, 산출물 간 ID 추적 체계를 관리합니다.

## 핵심 개념

### ID 추적 체인
모든 산출물은 하나의 ID 체인으로 연결됩니다:
```
제안요청ID (SFR-xxx)
  → 요구사항ID ({시스템코드}-RE-xxx)
    → 화면ID ({접두}_{xx}_{xx}_{xxx})
      → 프로그램ID (PG_{화면ID})
        → 단위테스트ID (U_{화면ID})
          → 통합테스트ID ({시스템코드}-TE-xxx)
```

이 체인이 끊기지 않도록 관리하는 것이 감리 대응의 핵심입니다.
`/추적매트릭스` 커맨드로 언제든 추적 상태를 확인하고 누락을 탐지할 수 있습니다.

### 시스템 코드
프로젝트의 각 시스템은 영문 1자리 코드(A~I)를 가집니다.
이 코드는 요구사항ID, 통합테스트ID의 접두어로 사용됩니다.

## 프로젝트 프로파일

`/프로젝트설정`으로 프로젝트 상황을 한 번 설정하면, 이후 모든 커맨드가 자동으로 활용합니다.
새 대화를 열어도 설정이 유지됩니다 (파일로 저장).

### 프로젝트 유형 4가지

| 유형 | 설명 |
|------|------|
| **A. 신규 구축** | RFP만 있고 코드 없음. 설계부터 시작 |
| **B. 추가 개발** | 운영 중 시스템에 새 기능 추가. 기존 유지 + 새 것 추가 |
| **C. 산출물 정비** | 개발 완료 후 산출물 역생성. 소스/DB에서 추출 |
| **D. 변경 관리** | 기존 기능 수정. 변경 대상 산출물만 갱신 |

### 기존 산출물 처리

커맨드 실행 시 기존 산출물이 있으면 3가지 선택지를 제공합니다:
- **이어쓰기**: 기존 유지 + 새 항목 추가 (ID 이어서 부여)
- **새로쓰기**: backup/ 폴더에 백업 후 처음부터 재생성
- **열기**: 기존 내용에서 특정 항목만 수정/삭제

## 승인 루프 & xlsx 추출

모든 커맨드는 **단계별 승인 루프**로 동작합니다:
0. **프로파일 로드**: 프로젝트 설정 자동 로드 + 기존 산출물 감지
1. 각 단계 산출물 생성 → 마크다운 표로 표시
2. **시안 감지**: 입력에 1안/2안 등 대안이 있으면 먼저 선택 요청
3. **승인 요청**: 사용자가 "승인"할 때까지 수정 → 재출력 반복
4. **xlsx 추출**: 승인 후 공공 양식에 맞는 xlsx로 추출 가능 (복붙용)

상세 규칙: `templates/approval-protocol.md` 참조

## 시작하기

1. **`/프로젝트설정`으로 프로젝트 프로파일 설정** (최초 1회)
2. `/요구사항정의서`로 요구사항 분석 시작
3. `/화면목록표`, `/프로그램정의서`, `/인터페이스정의서`로 설계 산출물 생성
4. `/테이블정의서`로 DDL ↔ 테이블정의서 변환
5. `/단위테스트계획서`, `/통합테스트시나리오`로 테스트 계획서 생성
6. `/추적매트릭스`로 전체 추적매트릭스 확인

### 산출물 정비 모드 (C유형)

개발 완료 후 산출물을 맞출 때는:
1. `/프로젝트설정`에서 유형을 **C. 산출물 정비**로 선택
2. 소스코드 경로와 DDL을 입력
3. `/프로그램정의서` → 소스코드에서 프로그램 목록 자동 역추출
4. `/테이블정의서` → DDL에서 테이블정의서 자동 역생성
5. `/인터페이스정의서` → API 호출 코드에서 인터페이스 자동 역추출

- AN-05 요구사항추적매트릭스
- DE-03 화면목록표
- DE-05 프로그램정의서
- DE-08 테이블정의서
- DE-13 단위테스트계획서 / IM-03 결과서
- DE-14 통합테스트계획서 / TE-02 결과서 / TE-06 인수테스트결과서

## 주의사항

- 모든 프로그램ID는 `PG_{화면ID}` 형식을 따릅니다
- 시스템코드는 영문 대문자 1자리 (A~I) 또는 프로젝트별 자유 코드
- 비기능 요구사항은 화면/프로그램 매핑 대상이 아닙니다
- 템플릿은 `templates/` 폴더에서 양식 상세를 확인할 수 있습니다
- **시안이 감지되면 반드시 사용자 선택을 받은 후 산출물을 생성합니다**
- **각 단계는 사용자 승인 없이 다음 단계로 진행하지 않습니다**
- xlsx 추출은 `utils/export-xlsx.py` 스크립트를 사용합니다 (openpyxl 자동 설치)
