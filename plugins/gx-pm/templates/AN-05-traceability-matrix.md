# AN-05 요구사항추적매트릭스 양식

## 파일 형식
Excel (.xlsx)

## 시트 구성
1. **표지**
2. **개정이력**
3. **요구사항추적 매트릭스(기능)** — 본문

## 본문 컬럼 구조 (4개 영역)

### 영역 1: 제안요청서(과업지시서)
| 컬럼 | 설명 |
|------|------|
| ID | 제안요청 ID (SFR-xxx) |
| 대분류 | 업무 대분류 |
| 중분류 | 업무 중분류 |
| 소분류 | 업무 소분류 |

### 영역 2: 요구사항
| 컬럼 | 설명 |
|------|------|
| ID | 요구사항 ID ({시스템코드}-RE-xxx) |
| 요구사항 | 요구사항 제목 |
| 요구사항 상세내역 | 상세 설명 |
| 해결/구현방안 | 구현 방법 |
| 제약사항 | 제약 조건 |
| 기능/비기능 | 구분 |
| 근거 | 과업지시서 등 |

### 영역 3: 설계단계
| 컬럼 | 설명 |
|------|------|
| 인터페이스 ID | 인터페이스 정의서의 ID |
| 인터페이스명 | 인터페이스 이름 |
| 테이블 ID | 테이블 정의서의 테이블명 |
| 화면 ID | 화면목록표의 화면 ID (복수 가능, 줄바꿈 구분) |
| 화면명 | 화면 이름 (복수 가능) |
| 프로그램 ID | 프로그램정의서의 ID (복수 가능) |
| 프로그램명 | 프로그램 이름 (복수 가능) |

### 영역 4: 검증
| 컬럼 | 설명 |
|------|------|
| 단위테스트 (ID/케이스명) | 단위테스트 ID와 케이스 |
| **테스트케이스 수** | 해당 화면에 작성된 TC 건수 ← v1.5.0 추가 |
| 통합테스트 (시나리오ID/명) | 통합테스트 시나리오 |
| **시스템테스트 (ID/항목)** | **비기능 요구사항의 검증 근거** ← v1.5.0 추가 |
| **잔존 결함** | 미조치 결함ID (Closed 아닌 건) ← v1.5.0 추가 |
| 과업완료여부 | 완료 여부 |
| 검사기준 | 검사기준서 참조 |

## 핵심 규칙

- 하나의 요구사항에 **복수의 화면/프로그램/테스트**가 매핑될 수 있음
- 복수 매핑 시 셀 내 **줄바꿈(\n)으로 구분**
- 모든 요구사항은 최소 하나의 화면, 프로그램, 테스트에 매핑되어야 함
- 누락된 매핑은 감리 지적 대상

## 요구사항 구분별 매핑 규칙

**기능 요구사항과 비기능 요구사항은 채워지는 컬럼이 다르다.** 같은 기준으로 누락을 판정하면 오탐이 난다.

| 컬럼 | 기능 요구사항 | 비기능 요구사항 |
|------|-------------|---------------|
| 화면ID / 화면명 | **필수** | 해당없음 (`-`) |
| 프로그램ID / 프로그램명 | **필수** | 해당없음 (`-`) |
| 단위테스트 / 테스트케이스 수 | **필수** | 해당없음 (`-`) |
| 통합테스트 | **필수** | 선택 |
| **시스템테스트** | 선택 | **필수** |

> 종전에는 비기능 요구사항의 검증 칸이 통째로 비었다.
> **시스템테스트ID가 비기능 요구사항의 검증 근거**이며, 이 칸이 비면 감리에서
> "비기능 요구사항 검증 누락"으로 지적된다.

## 커버리지 판정

| 지표 | 산식 | 목표 |
|------|------|------|
| 기능 요구사항 화면 매핑률 | 화면 매핑된 기능 요구사항 ÷ 전체 기능 요구사항 | 100% |
| **비기능 요구사항 검증률** | 시스템테스트 연결된 비기능 요구사항 ÷ 전체 비기능 요구사항 | **100%** |
| 테스트케이스 커버리지 | TC가 1건 이상 있는 화면 ÷ 전체 화면 | 100% |
| 결함 종결률 | Closed 결함 ÷ (전체 결함 − Rejected) | TE-01 종료기준 참조 |
