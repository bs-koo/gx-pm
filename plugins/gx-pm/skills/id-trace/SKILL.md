# ID 양방향 추적 (id-trace)

임의의 산출물 ID를 입력받아 해당 ID와 연결된 전체 추적 체인을 양방향으로 조회하고, 누락된 매핑을 탐지한다. 단건 추적과 전체 교차 검증 두 가지 모드를 제공한다.

## ID 체인 전체 구조

```
제안요청ID (SFR-xxx)
    ↓
요구사항ID ({시스템코드}-RE-xxx)
    ↓
화면ID ({접두}_{xx}_{xx}_{xxx})
    ↓                ↓
프로그램ID         단위테스트ID
(PG_{화면ID})      (U_{화면ID})
    ↓
통합테스트ID ({시스템코드}-TE-xxx)
```

## 입력

- 추적 모드 선택:
  - **단건 추적**: 특정 ID 1개 입력 → 해당 ID 기준 위·아래 전체 체인 추적
  - **전체 교차 검증**: "전체" 입력 → 모든 산출물의 모든 ID 교차 검증
- 산출물 데이터 (요구사항정의서, 화면목록표, 프로그램정의서, 테스트계획서, 추적매트릭스)

## ID 유형 자동 판별

입력된 ID를 정규식 패턴으로 자동 판별한다.

| ID 유형 | 정규식 패턴 | 예시 | 판별 근거 |
|--------|-----------|------|---------|
| 제안요청ID | `^SFR-\d{3}$` | SFR-027 | 고정 접두어 SFR + 3자리 숫자 |
| 요구사항ID | `^[A-I]-RE-\d{3}$` | B-RE-003 | 알파벳 1자(A~I) + -RE- + 3자리 |
| 화면ID | `^[A-Z]{3,4}_\d{2}_\d{2}_\d{3}$` | EHR_03_01_010 | 영문 접두어 + _숫자2_숫자2_숫자3 |
| 프로그램ID | `^PG_[A-Z]{3,4}_\d{2}_\d{2}_\d{3}$` | PG_EHR_03_01_010 | PG_ + 화면ID 패턴 |
| 단위테스트ID | `^U_[A-Z]{3,4}_\d{2}_\d{2}_\d{3}$` | U_EHR_03_01_010 | U_ + 화면ID 패턴 |
| 통합테스트ID | `^[A-I]-TE-\d{3}$` | B-TE-002 | 알파벳 1자(A~I) + -TE- + 3자리 |

- 패턴에 맞지 않는 ID 입력 시: "ID 형식을 인식하지 못했습니다. 형식을 확인해주세요." 안내 후 가장 유사한 유형 제안
- 화면ID와 프로그램ID/단위테스트ID는 PG_ / U_ 접두어로만 구분 → 접두어 없으면 화면ID로 우선 판별

## 처리 절차

### 모드 A: 단건 추적

#### Step 1: ID 유형 판별 및 시작 위치 결정

입력 ID의 유형을 위 정규식으로 판별하고, 체인에서의 위치(레벨)를 결정한다.

#### Step 2: 상향 추적 (입력 ID → 상위 체인)

입력 ID보다 상위에 있는 ID를 역방향으로 추적한다.

| 시작 ID 유형 | 상향 추적 경로 |
|-----------|------------|
| 화면ID | 화면ID → 요구사항ID → 제안요청ID |
| 프로그램ID | 프로그램ID → 화면ID → 요구사항ID → 제안요청ID |
| 단위테스트ID | 단위테스트ID → 화면ID → 요구사항ID → 제안요청ID |
| 통합테스트ID | 통합테스트ID → 요구사항ID → 제안요청ID |
| 요구사항ID | 요구사항ID → 제안요청ID |

#### Step 3: 하향 추적 (입력 ID → 하위 체인)

입력 ID보다 하위에 있는 ID를 순방향으로 추적한다.

| 시작 ID 유형 | 하향 추적 경로 |
|-----------|------------|
| 제안요청ID | 제안요청ID → 요구사항ID(복수 가능) → 화면ID → 프로그램ID + 단위테스트ID → 통합테스트ID |
| 요구사항ID | 요구사항ID → 화면ID(복수 가능) → 프로그램ID + 단위테스트ID → 통합테스트ID |
| 화면ID | 화면ID → 프로그램ID + 단위테스트ID |

#### Step 4: 트리 시각화 출력

추적 결과를 트리 형태로 출력한다. 트리 문자(┌─ ├─ │ └─)를 사용한다.

```
## ID 추적 결과 — B-RE-003

┌─ 제안요청: SFR-015 (교육 과정 관리 기능)
└─ 요구사항: B-RE-003 (교육 과정 등록/수정/삭제) ← [시작]
    ├─ 화면: EHR_03_01_010 (과정 목록)
    │   ├─ 프로그램: PG_EHR_03_01_010 ✅
    │   └─ 단위테스트: U_EHR_03_01_010 ✅
    ├─ 화면: EHR_03_01_020 (과정 등록)
    │   ├─ 프로그램: PG_EHR_03_01_020 ✅
    │   └─ 단위테스트: U_EHR_03_01_020 ⚠ 미작성
    └─ 통합테스트: B-TE-002 (과정 등록 및 수강 신청 흐름) ✅
```

- ✅: 해당 ID가 산출물에 등록되어 있음
- ⚠: 해당 위치에 ID가 있어야 하지만 누락됨
- ?: 산출물이 제공되지 않아 확인 불가

### 모드 B: 전체 교차 검증

#### Step 1: 모든 요구사항ID 수집

요구사항정의서의 모든 요구사항ID를 수집한다.

#### Step 2: 각 요구사항에 대해 하향 추적 수행

모든 요구사항에 대해 단건 추적의 하향 추적을 수행한다.

#### Step 3: 역방향 불일치 확인

하향 추적과 별도로 역방향 불일치를 확인한다:
- 화면목록표에 존재하지만 어떤 요구사항에도 매핑되지 않은 화면ID
- 프로그램정의서에 존재하지만 화면목록표에 없는 프로그램ID
- 테스트계획서에 존재하지만 추적매트릭스에 없는 테스트ID

#### Step 4: 전체 추적 완료율 계산

```
추적 완료율 = 과업완료 요구사항 수 / 전체 요구사항 수 × 100%
```

세부 완료율도 함께 계산한다:
- 화면 매핑률: 화면 매핑된 기능 요구사항 / 전체 기능 요구사항 × 100%
- 프로그램 등록률: 프로그램ID 있는 화면 / 전체 화면 × 100%
- 단위테스트 작성률: 단위테스트ID 있는 화면 / 전체 화면 × 100%
- 통합테스트 연결률: 통합테스트 연결된 요구사항 / 전체 요구사항 × 100%

## 누락 탐지 4가지 유형

| 유형 | 정의 | 탐지 방법 |
|------|------|---------|
| **화면 미매핑** | 기능 요구사항인데 화면ID가 없음 | 요구사항정의서 구분=기능 AND 추적매트릭스 화면ID 공백 |
| **프로그램 미등록** | 화면ID는 있는데 프로그램정의서에 PG_{화면ID}가 없음 | 화면목록표 화면ID SET - 프로그램정의서 화면ID SET |
| **테스트 미작성** | 화면ID는 있는데 단위테스트계획서에 U_{화면ID}가 없음 | 화면목록표 화면ID SET - 단위테스트계획서 테스트ID에서 U_ 제거한 SET |
| **역방향 불일치** | 화면/프로그램/테스트가 어떤 요구사항에도 연결되지 않음 | 추적매트릭스 매핑 역방향 검증 |

## 출력

### 단건 추적 출력

```
## ID 추적 결과 — {입력 ID}

{트리 시각화}

### 누락 항목
- ⚠ U_EHR_03_01_020: 단위테스트ID 미작성
```

### 전체 교차 검증 출력

```
## 전체 ID 교차 검증 결과 — {시스템명}

### 추적 완료율
| 항목 | 완료 | 전체 | 완료율 |
|------|------|------|--------|
| 전체 요구사항 과업완료 | N | N | N% |
| 기능 요구사항 화면 매핑 | N | N | N% |
| 화면 → 프로그램 등록 | N | N | N% |
| 화면 → 단위테스트 작성 | N | N | N% |
| 요구사항 → 통합테스트 연결 | N | N | N% |

### 누락 목록

#### 화면 미매핑 (N건)
| 요구사항ID | 요구내역 |
|-----------|--------|
| B-RE-010 | 교육 수료 증명서 발급 |

#### 프로그램 미등록 (N건)
| 화면ID | 화면명 | 연결 요구사항ID |
|-------|------|-------------|
| EHR_05_02_010 | 수료증 발급 | B-RE-010 |

#### 테스트 미작성 (N건)
| 화면ID | 화면명 | 연결 요구사항ID |
|-------|------|-------------|
| EHR_03_01_020 | 과정 등록 | B-RE-003 |

#### 역방향 불일치 (N건)
| ID | 유형 | 불일치 내용 |
|----|------|-----------|
| EHR_07_01_010 | 화면ID | 추적매트릭스에 미연결 |
```

## 체크포인트

추적 결과를 사용자에게 확인한다:

"ID 추적 결과를 확인해주세요:
- B-RE-003: 화면 2개 매핑, U_EHR_03_01_020 단위테스트 누락 ⚠
- 전체 추적 완료율: N/N = N%
- 누락 항목 총 N건 발견
추적매트릭스(AN-05) 보완이 필요하면 trace-requirements 스킬을 사용하세요.
누락 항목을 한 번에 정리할까요?"

## 주의사항

- 비기능 요구사항은 화면ID/프로그램ID 누락이 정상 — 화면 미매핑으로 오탐하지 않도록 구분=비기능 항목은 제외
- 수용여부 "불가" 요구사항도 화면 미매핑 오탐 제외 대상
- 화면ID와 프로그램ID가 PG_ 접두어만 다른 경우 자동 연결로 처리
- 통합테스트는 여러 요구사항을 묶는 시나리오 단위 → 1:N 매핑이 정상
- 전체 교차 검증 모드는 산출물 데이터가 모두 제공된 경우에 가장 정확 — 일부만 있으면 확인 불가 항목(?)으로 표시
