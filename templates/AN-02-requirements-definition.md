# AN-02 요구사항정의서 양식

## 파일 형식
Excel (.xlsx)

## 시트 구성
1. **표지** — 프로젝트명, 문서명
2. **개정이력** — 버전, 개정일, 개정사유, 개정내용, 작성자, 승인자
3. **요구사항정의서(기능)** — 본문 데이터

## 본문 컬럼 구조

| 컬럼 | 설명 | 예시 |
|------|------|------|
| 제안요청ID | RFP 항목 ID | SFR-001 |
| 요구사항ID | 요구사항 고유 ID | B-RE-001 |
| 구분 | 기능/비기능 | 기능 |
| 근거 | 요구사항 출처 | 과업지시서 |
| 대분류 | 업무 대분류 | 공공기관관리 통합 안내 사이트 |
| 중분류 | 업무 중분류 | 통합 안내 사이트 구축 |
| 소분류 | 업무 소분류 | (선택) |
| 요구내역 | 요구사항 제목/요약 | ㅇ 시스템별 주요 기능 소개 페이지 제공 |
| 요구사항 상세내역 | 상세 설명 | 각 시스템의 주요 기능과 제도 개요를... |
| 수용여부 | 수용/부분수용/불가 | 수용 |

## 작성 규칙

- 요구사항ID 첫 글자는 시스템 구분코드 (A~I)
- 하나의 제안요청ID에 여러 요구사항ID가 매핑될 수 있음
- 제안요청ID가 동일한 행은 첫 행에만 ID를 기재하고 이후 행은 빈칸
- 수용여부가 "부분수용" 또는 "불가"인 경우 사유를 별도 컬럼이나 비고에 기재
