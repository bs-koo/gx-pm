# DE-03 화면목록표 양식

## 파일 형식
Excel (.xlsx)

## 시트 구성
1. **표지**
2. **개정이력**
3. **화면목록표** — 본문

## 본문 컬럼 구조

| 컬럼 | 설명 | 예시 |
|------|------|------|
| 기능구분ID | 기능 그룹 ID | EHR_01 |
| 기능구분명 | 기능 그룹 이름 | 시스템관리 |
| 기능ID | 세부 기능 ID | EHR_01_01 |
| 기능명 | 세부 기능 이름 | 운영자 권한 관리 |
| SN | 화면 일련번호 (010, 020...) | 010 |
| 화면ID (자동계산) | {기능ID}_{SN} | EHR_01_01_010 |
| 화면명 | 화면 이름 | 운영자 권한 관리 |
| 망 구분 | 내부/외부 | 내부 |
| 담당자 | 개발 담당자 | 홍길동 |
| 개발예정일 UI | UI 개발 예정일 | 2025-06-18 |
| 개발예정일 LOGIC | 로직 개발 예정일 | 2025-08-31 |
| 개발진행 UI | UI 진행률 (0~1) | 1 |
| 개발진행 LOGIC | 로직 진행률 (0~1) | 0.9 |
| 신규/변경 | 신규 또는 변경 | 신규 |
| 비고 | 참고사항 | |

## 화면ID 생성 규칙

- 화면ID = `{기능ID}_{SN}`
- SN은 010부터 시작, 10 단위 증가 (010, 020, 030...)
- 같은 기능ID 아래 여러 화면이 존재 가능
- 기능구분ID가 동일한 행은 첫 행에만 기재
