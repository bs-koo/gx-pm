# DE-13 단위테스트계획서 양식

### 공통부문 (8개)
| 코드 | 항목명 | 설명 |
|------|--------|------|
| 공통부문(1) | 표준 준수 | UI 표준을 준수하여 화면을 구성하였는지 확인 |
| 공통부문(2) | 정상 표출 | 화면 UI에 버튼, 이미지, 테이블 등이 깨짐 및 누락없이 정상 OPEN |
| 공통부문(3) | 화면 이동 | 네비게이션(메뉴, 탭) 선택에 따라 정상 이동 |

| 공통부문(5) | 화면 Default | 날짜, 필수, 체크그램 등의 초기값이 정상 설정 |
