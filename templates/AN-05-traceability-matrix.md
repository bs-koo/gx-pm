# AN-05 요구사항추적매트릭스 양식

## 파일 형식
Excel (.xlsx)

## 시트 구성
1. **표지**
2. **개정이력**
3. **요구사항추적 매트릭스(기능)** — 본문

## 본문 컬럼 구조 (4개 영역)

### 영역 1: 제안요청서(과업지시서)
| 컬럼 | 설명 |
|------|------|
| ID | 제안요청 ID (SFR-xxx) |
| 대분류 | 업무 대분류 |
| 중분류 | 업무 중분류 |
| 소분류 | 업무 소분류 |

### 영역 2: 요구사항
| 컬럼 | 설명 |
|------|------|
| ID | 요구사항 ID ({시스템코드}-RE-xxx) |
| 요구사항 | 요구사항 제목 |
| 요구사항 상세내역 | 상세 설명 |
| 해결/구현방안 | 구현 방법 |
| 제약사항 | 제약 조건 |
| 기능/비기능 | 구분 |
| 근거 | 과업지시서 등 |

### 영역 3: 설계단계
| 컬럼 | 설명 |
|------|------|
| 인터페이스 ID | 인터페이스 정의서의 ID |
| 인터페이스명 | 인터페이스 이름 |
| 테이블 ID | 테이블 정의서의 테이블명 |
| 화면 ID | 화면목록표의 화면 ID (복수 가능, 줄바꿈 구분) |
| 화면명 | 화면 이름 (복수 가능) |
| 프로그램 ID | 프로그램정의서의 ID (복수 가능) |
| 프로그램명 | 프로그램 이름 (복수 가능) |

### 영역 4: 검증
| 컬럼 | 설명 |
|------|------|
| 단위테스트 (ID/케이스명) | 단위테스트 ID와 케이스 |
| 통합테스트 (시나리오ID/명) | 통합테스트 시나리오 |
| 과업완료여부 | 완료 여부 |
| 검사기준 | 검사기준서 참조 |

## 핵심 규칙

- 하나의 요구사항에 **복수의 화면/프로그램/테스트**가 매핑될 수 있음
- 복수 매핑 시 셀 내 **줄바꿈(\n)으로 구분**
- 모든 요구사항은 최소 하나의 화면, 프로그램, 테스트에 매핑되어야 함
- 누락된 매핑은 감리 지적 대상
