# 검사기준 참조

## 공통부문 검사기준 (단위테스트에서 참조)

| 번호 | 항목 | 검사 내용 |
|------|------|----------|
| (1) | 표준 준수 | UI 표준을 준수하여 화면을 구성하였는지 확인한다. |
| (2) | 정상 표출 | 화면 UI에 버튼, 이미지, 테이블 등이 깨짐 및 누락없이 정상적으로 OPEN 되는지 확인한다. |
| (3) | 화면 이동 | 네비게이션(메뉴, 탭) 선택에 따라 정상적으로 이동하는지 확인한다. |
| (4) | 화면 Title | 화면 타이틀이 메뉴 선택과 일치하는지 확인한다. |
| (5) | 화면 Default | 날짜, 필수, 체크그램 등의 초기값이 정상적으로 설정되어 있는지 확인한다. |
| (6) | 화면 Button | 화면 버튼이 상태에 따라 정상적으로 활성화되어 있는지 확인한다. |
| (7) | 권한 | 사용자 권한에 따른 메뉴/기능 접근 제어가 정상 동작하는지 확인한다. |
| (8) | 에러 처리 | 예외 상황 발생 시 적절한 에러 메시지가 표시되는지 확인한다. |

## 판정 기준

| 판정 | 의미 |
|------|------|
| 적합 | 검사 항목을 충족함 |
| 부적합 | 검사 항목을 충족하지 못함 (조치 필요) |
| 해당없음 | 해당 화면에 적용되지 않는 항목 |
