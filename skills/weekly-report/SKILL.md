# 주간보고서 생성 (weekly-report)

금주 활동 내역, 이슈/리스크, 차주 계획을 입력받아
공공/SI 프로젝트 표준 주간업무보고서를 생성한다.

---

## Step 1: 기본 정보 수집

```
[주간보고서 기본 정보]
- 프로젝트명:
- 프로젝트 코드:
- PM:
- 작성자:
- 보고 기간: YYYY-MM-DD(월) ~ YYYY-MM-DD(금)
- 보고 회차: 제 N주차
- 현재 단계: (분석 / 설계 / 구현 / 시험)
- 감리 기간 여부: (해당 / 해당없음)
  → 해당 시: 감리 종료일 YYYY-MM-DD
```

---

## Step 2: 금주 실적 입력

수행한 업무를 항목별로 입력받는다. 화면목록표의 개발진행 컬럼이 있으면 자동 산출을 안내한다.

```
[금주 실적 입력 형식]
업무내용 | 산출물(문서번호 포함) | 진척률(%) | 비고

예시:
화면 설계 완료 (SCR-011~020) | 화면설계서(DE-05) | 80% | 10개 화면 중 8개 완료
단위테스트 계획서 작성 | 단위테스트계획서(DE-13) | 100% |
```

### 진척률 자동 산출 안내

화면목록표(DE-01)의 "개발진행" 컬럼 데이터가 있는 경우:

```
[자동 산출 방법]
- 완료: 전체 화면 수 대비 "완료" 상태 화면 비율
- 진행중: 전체 화면 수 대비 "진행중" 상태 화면 비율

예시: 전체 120개 화면 중 완료 60개, 진행중 20개
→ 구현 진척률: 완료 50% / 진행중 포함 66.7%

※ 화면목록표 데이터를 붙여넣으시면 자동 계산해 드립니다.
```

---

## Step 3: 이슈/리스크 입력

```
[이슈/리스크 입력 형식]
유형 | 내용 | 영향도 | 대응방안 | 상태

유형: 이슈(현재 발생) / 리스크(발생 가능성)
영향도: 높 / 중 / 저
상태: 해결 / 진행중 / 미착수

예시:
이슈 | 발주처 요구사항 변경 (로그인 방식 변경) | 높 | 영향도 분석 후 공수 조정 협의 | 진행중
리스크 | 외부 API 연동 지연 가능성 | 중 | 대체 방안 사전 검토 중 | 미착수
```

---

## Step 4: 단계별 진척률 입력

각 단계의 계획 진척률과 실적 진척률을 입력받는다.

```
[단계별 진척률 입력]
단계 | 계획(%) | 실적(%) | 비고

예시:
분석 | 100% | 100% | 완료
설계 | 100% | 95% | 화면설계 일부 미완
구현 | 60% | 50% | 2주 지연
시험 | 0% | 0% | 미착수
```

전체 진척률 자동 계산:
- 각 단계 가중치가 있는 경우 적용
- 없는 경우: 4단계 단순 평균으로 산출

---

## Step 5: 감리 대응 현황 (감리 기간인 경우)

Step 1에서 감리 기간 "해당"으로 입력된 경우만 해당 섹션을 생성한다.

```
[감리 대응 현황 입력]
- 감리 지적사항 총 건수:
- 조치 완료:
- 조치 진행중:
- 미착수:
- 감리 종료일까지 남은 일수: (자동 계산)

비고: 주요 지적사항 요약 (있으면)
```

---

## Step 6: 주요 의사결정 사항 입력

이번 주에 결정된 주요 사항을 입력받는다.

```
[주요 의사결정 입력 형식]
결정사항 | 결정일 | 결정자/협의자 | 비고

예시:
인증 방식 SAML 2.0으로 최종 확정 | 2025-03-19 | 발주처 김팀장, PM 홍길동 |
2차 중간보고회 일정 4월 2일로 확정 | 2025-03-20 | 발주처 김팀장 |
```

---

## Step 7: 차주 계획 입력

```
[차주 계획 입력 형식]
업무내용 | 예정 산출물 | 기한

예시:
화면 설계 잔여분 완료 | 화면설계서(DE-05) | 2025-03-28
단위테스트 수행 시작 | - | 2025-03-26
```

## 체크포인트 (사용자 확인 요청)

```
[최종 확인]
1. 실적 진척률이 계획 대비 5% 이상 지연된 단계가 있습니다. 지연 사유를 이슈 섹션에 추가하시겠습니까?
2. 이슈 중 영향도 "높"인 항목이 있습니다. 주간회의 안건으로 올리시겠습니까?
3. 감리 대응 현황 미착수 항목이 있습니다. 종료일까지 D-{N}일입니다. 조치 계획을 차주 계획에 추가하시겠습니까?
4. 보고서를 최종 확정하시겠습니까?
```

---

## 주의사항 및 규칙

1. 보고 기간은 반드시 월~금(5일) 기준으로 작성
2. 진척률 편차(계획 - 실적)가 음수인 경우 빨간 강조 표시 권고
3. 산출물 기재 시 문서번호(예: DE-05, IM-03) 함께 기재
4. 이슈/리스크 영향도 "높"은 반드시 대응방안을 구체적으로 기술
5. 감리 기간이 아닌 경우 "4. 감리 대응 현황" 섹션 전체 생략
6. 주요 의사결정 사항이 없는 경우 "금주 주요 의사결정 없음"으로 명시
7. 전체 진척률 계산 시 가중치 적용 여부를 사용자에게 확인
