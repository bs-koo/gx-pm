# /pm-test — 테스트 계획서 생성

화면목록표(DE-03)와 요구사항정의서(AN-02)를 기반으로 단위테스트계획서(DE-13)와 통합테스트계획서(DE-14)를 자동 생성하는 워크플로우.

## 호출 예시

```
/pm-test
/pm-test [화면목록표 업로드]
/pm-test B 시스템 테스트 계획서 만들어줘
```

## 워크플로우

### Step 1: 입력 데이터 로드

- 이전 `/pm-design` 결과가 있으면 자동 로드
- 없으면 화면목록표 입력 요청
- 요구사항정의서도 함께 로드 (통합테스트용)

### Step 2: 단위테스트계획서 생성

**generate-unit-test-plan** 스킬 적용:
1. 화면 목록 파싱
2. 화면 유형 판별 (목록형/등록형/수정형/상세형/CRUD통합형)
3. 검사기준 자동 매핑 (공통/조회/입력/수정/삭제/첨부/출력)
4. 단위테스트ID 부여 (U_{화면ID})
5. 사용자구분 판별

체크포인트: "화면 유형 판별 결과를 확인해주세요"

### Step 3: 통합테스트시나리오 생성

**generate-integration-test** 스킬 적용:
1. 요구사항-화면 매핑
2. 업무 흐름 기반 시나리오 그룹핑
3. 통합테스트ID 부여 ({시스템코드}-TE-{순번})
4. Step 분해 (사용자행위 → 시스템결과)
5. 테스트 데이터 제안

체크포인트: "시나리오 구성을 확인해주세요"

### Step 4: 결과 저장

- `{시스템코드}-단위테스트계획서.md`
- `{시스템코드}-통합테스트시나리오.md`

### Step 5: 다음 단계 제안

- "/pm-trace 로 추적매트릭스를 완성할까요?"
- "개발 완료 후 fill-unit-test-result 스킬로 결과서를 작성할 수 있습니다."
