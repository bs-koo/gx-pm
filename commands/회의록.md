# /회의록 — 회의록 생성

> **공통 규칙**: `templates/approval-protocol.md`의 승인 루프 프로토콜을 적용한다.

## 워크플로우

### Step 1: 회의 기본 정보 수집 [필수 중단점]

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 회의 기본 정보를 입력해주세요

1. 회의 일시:
2. 회의 장소:
3. 회의 유형: (착수/중간/감리/정기/긴급/기타)
4. 참석자: (이름, 소속 — 발주처/감리단/개발팀 구분)
5. 회의 내용: (녹취 전사, 메모, 슬랙 대화 등 붙여넣기)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

답변이 올 때까지 다음 단계로 진행하지 않는다.

### Step 2: 회의록 작성

**meeting-notes** 스킬 적용:
- 참석자 구분 (발주처/감리단/개발팀)
- 안건별 논의 내용 구조화
- 지시사항(발주처→개발팀), 협의사항 추출
- 결정사항 + 액션아이템 테이블 생성
- 회의록 번호 부여 ({프로젝트코드}-MTG-{순번})

### Step 3: 회의록 검토 [필수 중단점 — 승인 루프]

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 회의록을 확인해주세요

✅ 승인 — "승인" 또는 "OK"
✏️ 수정 — 변경 내용 입력

  수정 예시:
  • "결정사항 2번 삭제"
  • "액션아이템에 '추적매트릭스 보완' 추가, 담당: 김철수"
  • "참석자에 '박영희 (감리단)' 추가"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

사용자가 승인할 때까지 수정 → 재출력 → 승인 요청을 반복한다.

### Step 4: 결과 저장 + xlsx 추출

파일명: `{프로젝트코드}-MTG-{순번}.md`

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 xlsx로 추출할까요?
  1. xlsx 추출  2. 마크다운만 저장
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### Step 5: 후속 제안

- 감리회의: "/감리대응 으로 지적사항 대응을 시작할까요?"
- 지시사항 존재: "액션아이템을 이슈로 등록할까요?"
