# /pm-report — 보고 문서 생성

회의록 또는 주간보고서를 공공/SI 프로젝트 표준 양식으로 생성하는 워크플로우.

> **공통 규칙**: 모든 체크포인트에서 `templates/approval-protocol.md`의 승인 루프 프로토콜을 적용한다.

## 호출 예시

```
/pm-report 회의록              # 회의록 작성
/pm-report 주간보고            # 주간보고서 작성
/pm-report                    # 유형 선택부터 시작
```

## 워크플로우

### Step 1: 보고서 유형 선택

인자가 없으면 사용자에게 선택:
1. 회의록 — 회의 내용을 구조화 (결정사항, 지시사항, 액션아이템 추출)
2. 주간보고서 — 금주 실적, 이슈, 진척률, 차주 계획

### [회의록] Step 2a: 회의 기본 정보 수집 [필수 중단점]

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 회의 기본 정보를 입력해주세요

1. 회의 일시:
2. 회의 장소:
3. 회의 유형: (착수/중간/감리/정기/긴급/기타)
4. 참석자: (이름, 소속 — 발주처/감리단/개발팀 구분)
5. 회의 내용: (녹취 전사, 메모, 슬랙 대화 등 붙여넣기)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### [회의록] Step 3a: 회의록 작성

**meeting-notes** 스킬 적용:
1. 입력 유형 파악 (녹취 전사 / 메모 / 슬랙 대화)
2. 참석자 구분 (발주처 / 감리단 / 개발팀)
3. 안건별 논의 내용 구조화
4. 공공/SI 특화 추출: 지시사항(발주처→개발팀), 협의사항
5. 결정사항 + 액션아이템 테이블 생성
6. 회의록 번호 부여 ({프로젝트코드}-MTG-{순번})

### [주간보고] Step 2b: 주간보고 기본 정보 수집 [필수 중단점]

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 주간보고 기본 정보를 입력해주세요

1. 보고 기간: (예: 2026.03.23 ~ 03.27)
2. 현재 단계: (분석/설계/구현/시험)
3. 감리 여부: (감리 기간인지 여부)
4. 금주 실적: (주요 업무 내용 자유 입력)
5. 이슈/리스크: (있으면 입력)
6. 차주 계획: (있으면 입력)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### [주간보고] Step 3b: 주간보고서 작성

**weekly-report** 스킬 적용:
1. 금주 실적 구조화 (업무, 산출물, 진척률)
2. 이슈/리스크 정리 (유형, 영향도, 대응방안)
3. 단계별 진척률 (분석/설계/구현/시험 계획 vs 실적)
4. 감리 대응 현황 (감리 기간인 경우)
5. 차주 계획 정리

### Step 4: 보고서 검토 [필수 중단점 — 승인 루프]

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 보고서 내용을 확인해주세요

✅ 승인 — "승인" 또는 "OK"
✏️ 수정 — 변경 내용 입력

  수정 예시:
  • "결정사항 2번 삭제"
  • "액션아이템에 '추적매트릭스 보완' 추가, 담당: 김철수"
  • "진척률을 설계 70% → 80%로 수정"
  • "이슈에 '감리 일정 변경' 추가"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

사용자가 승인할 때까지 수정 → 재출력 → 승인 요청을 반복한다.

### Step 5: 결과 저장 + xlsx 추출

- 회의록: `{프로젝트코드}-MTG-{순번}.md`
- 주간보고: `주간보고서-{YYYYMMDD}.md`

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 보고서를 xlsx로 추출할까요?
  1. xlsx 추출
  2. 마크다운만 저장
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### Step 6: 후속 제안

회의록:
- 감리회의인 경우: "/pm-audit 로 지적사항 대응을 시작할까요?"
- 지시사항이 있는 경우: "액션아이템을 Redmine 이슈로 등록할까요?"

주간보고:
- 진척률 지연 시: "지연 사유를 이슈 섹션에 추가할까요?"
- 감리 미조치 항목 시: "/pm-audit 로 조치 계획을 확인할까요?"
