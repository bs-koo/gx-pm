# /pm-trace — ID 추적 + 누락 탐지

요구사항 → 화면 → 프로그램 → 테스트까지의 ID 체인을 양방향으로 추적하고, 누락된 매핑을 탐지하여 추적매트릭스(AN-05)를 갱신하는 워크플로우.

## 호출 예시

```
/pm-trace B-RE-003             # 특정 요구사항 ID 추적
/pm-trace EHR_01_01_010        # 특정 화면 ID 추적
/pm-trace 전체                  # 전체 산출물 교차 검증
/pm-trace                      # 대화형 시작
```

## 워크플로우

### Step 1: 추적 모드 결정

- 특정 ID 입력 → 단건 추적 모드
- "전체" → 전체 교차 검증 모드
- 없으면 → 사용자에게 선택 요청

### [단건] Step 2a: 단건 ID 추적

**id-trace** 스킬 적용:
1. ID 유형 자동 판별 (요구사항/화면/프로그램/테스트)
2. 양방향 추적 체인 출력:
   ```
   ┌─ 제안요청: SFR-027
   ├─ 요구사항: B-RE-003
   │   ├─ 화면: EHR_17_01_010 (그린캠퍼스기 인증 신청)
   │   │   ├─ 프로그램: PG_EHR_17_01_010
   │   │   └─ 단위테스트: U_EHR_17_01_010
   │   └─ 통합테스트: A-TE-001
   └─ 과업완료: ✅
   ```
3. 누락된 매핑 표시: ⚠

### [전체] Step 2b: 전체 교차 검증

1. 모든 산출물 데이터 로드 (요구사항, 화면, 프로그램, 테스트)
2. 각 요구사항에 대해 전체 추적 체인 확인
3. 누락 리포트 생성:
   ```
   ⚠ 누락 발견 3건:
   - B-RE-005: 화면ID 미매핑
   - EHR_03_02_010: 단위테스트ID 누락
   - A-TE-003: 요구사항ID 미연결
   ```

### Step 3: 추적매트릭스 갱신

**trace-requirements** 스킬 적용:
- 현재까지의 매핑 정보를 AN-05 추적매트릭스 형식으로 종합
- 설계/구현/시험 단계 컬럼 채우기
- 과업완료여부 판정

### Step 4: 결과 저장

- `{시스템코드}-추적매트릭스.md`

### Step 5: 다음 행동 제안

누락이 있으면:
- "누락된 {N}건을 채울까요?"
- 해당 산출물 생성 커맨드 제안
