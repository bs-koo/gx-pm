# /pm-analyze — 요구사항 분석

RFP, 과업지시서, 제안서에서 요구사항을 추출하여 AN-02 요구사항정의서 형식으로 정리하는 워크플로우.

> **공통 규칙**: 모든 체크포인트에서 `templates/approval-protocol.md`의 승인 루프 프로토콜을 적용한다.

## 호출 예시

```
/pm-analyze 과업지시서에서 요구사항 뽑아줘
/pm-analyze [파일 업로드]
/pm-analyze                    # 대화형 시작
```

## 워크플로우

### Step 1: 프로젝트 기본 정보 수집 [필수 중단점]

사용자에게 아래 정보를 **반드시** 확인받는다. 답변이 올 때까지 다음 단계로 진행하지 않는다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 프로젝트 기본 정보를 입력해주세요

1. 시스템 코드: 영문 1자리(A~I) 또는 신규 프로젝트명
   예) A, B, ... 또는 자유 코드 (ACT 등)

2. 시스템 접두어: 화면ID에 사용할 2~4자리 영문
   예) EHR, KSC, ACT

3. 망 구분: 이 시스템의 네트워크 환경은?
   (1) 내부망 전용  (2) 외부망 전용  (3) 내부+외부 혼재

4. 작성자명: 감리 대응 담당자
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

기존 산출물이 있으면 기존 ID 체계를 자동 감지하여 제안한다.

### Step 2: 시안/대안 감지 [필수 중단점]

**detect-alternatives** 스킬 적용:
- 입력 문서 전체를 스캔하여 시안(1안/2안), 대안, 선택지를 감지
- 감지된 시안이 있으면 사용자에게 선택을 요청

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠ 시안 선택이 필요합니다

  1안: {시안1 요약}
  2안: {시안2 요약}

→ 어떤 시안으로 진행할까요? (1/2/병행)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

시안이 감지되지 않으면 이 단계를 건너뛴다.
사용자가 선택할 때까지 요구사항 추출을 시작하지 않는다.

### Step 3: 요구사항 추출

**extract-requirements** 스킬 적용:
- RFP/과업지시서에서 기능 요구사항 추출
- "ㅇ", "o"로 시작하는 항목, "~해야 한다" 패턴 식별
- 요구사항ID 자동 부여 ({시스템코드}-RE-{순번})
- Step 2에서 선택된 시안만 반영 (병행 선택 시 양쪽 모두 포함하되 태그 구분)

### Step 4: 요구사항 분류

**classify-requirements** 스킬 적용:
- 기능/비기능 분류
- 대분류/중분류/소분류 자동 분류
- 수용여부 초안 (수용/부분수용/불가)

### Step 5: 요구사항 검토 [필수 중단점 — 승인 루프]

추출된 요구사항 표를 사용자에게 표시한다.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 추출된 요구사항 {N}건을 확인해주세요

✅ 승인 — "승인" 또는 "OK" 입력
✏️ 수정 — 아래에 변경할 내용을 입력해주세요

  수정 예시:
  • "ACT-RE-003과 004를 하나로 합쳐줘"
  • "비기능 요구사항에 보안 항목 추가해줘"
  • "5번 행의 수용여부를 부분수용으로 변경"
  • "대분류 '입력 관리'를 '환경변수 관리'로"

  혹시 선택이 필요한 부분이 있나요?
  (문서에서 놓친 시안/대안이 있으면 알려주세요)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

사용자가 승인할 때까지 수정 → 재출력 → 승인 요청을 반복한다.

### Step 6: 우선순위 부여 (선택)

**prioritize-si** 스킬 적용 (사용자 선택 시):
- 공공/SI 5단계 우선순위 (P1 법적필수 ~ P5 품질개선)
- 영향도(높/중/저) + 시급도 매트릭스
- 감리 지적 고위험 항목 자동 식별

"요구사항에 우선순위를 부여할까요?" → 사용자 승인 시 실행

### Step 7: 결과 저장 + xlsx 추출

확정된 요구사항을 마크다운 파일로 저장:
- 파일명: `{시스템코드}-요구사항정의서.md`

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 승인된 요구사항정의서를 xlsx로 추출할까요?
  1. xlsx 추출 (산출물 엑셀에 바로 복붙 가능)
  2. 마크다운만 저장
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

xlsx 선택 시 `utils/export-xlsx.py`를 실행하여 공공 양식 컬럼 순서에 맞춘 xlsx를 생성한다.
